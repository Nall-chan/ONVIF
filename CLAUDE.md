# Diese Library: ONVIF  

- Diese Library dient zur Anbindung von ONVIF kompatiblen Geräten, wie Kameras, NVR oder Encodern, an die Software IP-Symcon. Sie stellt die notwendigen Module und Funktionen bereit, um das ONVIF Protokoll, welches auf SOAP+XML und WSDL basiert in IP-Symcon zu integrieren und zu steuern.
- Die Library ist so konzipiert, dass sie leicht erweiterbar ist, um fehlende Abschnitte bei der Erweiterung der ONVIF Specs zu ergänzen.  
- Quellen:
  - ONVIF-Specs: `https://www.onvif.org/profiles/specifications/`
  - ONVIF Repository: `https://github.com/onvif/specs`
